# LinkedIn draft — 3D Printer

Status: Draft based on owner-confirmed details, with the GitHub project link included. Not posted to LinkedIn.

I built my own 3D printer, starting with a 2020-profile frame and working through the build without following a reference build.

It took a lot of time to put together. The total cost came to approximately INR 15,000.

The most time-consuming part was developing settings for my own build. I worked through the calibrations one by one, gradually putting together the settings for the printer.

The printer uses NEMA 17 motors and GT2 belts for X/Y motion, dual Z motors, and a RAMPS 1.4 + Arduino Mega setup running Marlin. It has BLTouch bed leveling and a 200 x 200 mm bed and firmware-configured print limits of 200 x 200 x 200 mm.

I've used it to print a PLA headphone stand and a figurine, which I painted after printing.
I use MatterControl for printing.

I'm documenting the components, Y gantry CAD, build photos, and print results in my project portfolio.

Project files and build notes: [My 3D printer project](https://github.com/vivek5391/project-portfolio/tree/main/projects/01-3d-printer)
